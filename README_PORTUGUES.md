# Aplicativo Bancário Simplificado

Este é um aplicativo simples de conta bancária.

## Funcionalidades
- Login e criação de conta
- Transferência de dinheiro entre contas

## Painel (Dashboard)
- Informações da conta
- Saldo, receitas e despesas
- Movimentações

## Linguagens de programação
- JavaScript
- CSS
- HTML

## Como usar:
Crie uma conta clicando em "Criar conta" (Create account) e faça o login com o número da sua conta.
Isso o levará ao painel de controle, onde terá uma visão geral da conta e poderá realizar as operações.
